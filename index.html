+ 새 활동 추가하는 법

세 단계면 충분합니다. 코드를 직접 몰라도 아래 틀만 그대로 복사해서 값만 바꾸면 돼요.

STEP 1새로 만든 웹앱 HTML 파일을 이 index.html과 같은 폴더의 apps 폴더 안에 넣습니다.
STEP 2index.html을 메모장(또는 코드 편집기)으로 열고, 아래 목록(appsData)에 항목 하나를 복사해 붙여넣은 뒤 내용만 바꿉니다.
STEP 3저장하고 index.html을 새로고침하면 카드가 자동으로 나타납니다. 별도 설치나 서버가 필요 없습니다.
{
  unit: "cell",        // cell(세포) · metabolism(물질대사와 에너지) · respiration(세포호흡과 광합성) · etc(기타)
  no: "02",
  title: "삼투 현상 시뮬레이션",
  desc: "반투과성막을 경계로 물이 이동하는 삼투 현상을 관찰합니다.",
  tags: ["#삼투", "#반투과성막", "#세포"],
  file: "apps/osmosis_simulation.html",
  status: "ready"   // ready(바로 열기) · todo(준비 중 표시만)
}
